# 阿酷 · 潮酷少年桌面宠物（Windows .exe）

一只「不挡事、会来事」的桌面宠物。Q 版潮酷少年，黑发挑染、咬链条、傲娇冷幽默，
基于参考图人设用 **QPainter 全程序化渲染**，所以眨眼、视线跟随、抓取挣扎、落回挤压、
墨镜、跳舞、大招……全部平滑可控，比贴图宠物更耐玩。

![预览](preview_out/_sheet.png)

## 一、玩法一览

### 1. 灵动的即时微交互
| 操作 | 反应 |
|---|---|
| 移动鼠标靠近 | 视线跟随瞳孔转动，光标贴近时会警觉/好奇 |
| 悬停片刻 | 歪头 / 咬链条招牌动作，随机冒台词 |
| 单击 | 随机表情：Wink、傲娇撇嘴、惊讶 |
| 双击 | 开心 / 爱心眼（会冒小心心） |
| 按住拖拽 | 被抓着悬空，快速甩动会挣扎、冒汗、喊"放我下来" |
| 松手 | 抛出去会带物理回弹落地、挤扁变形、转圈头晕 |
| 快速来回抚摸 | 脸红害羞，飘小爱心 |

### 2. 自主活动与环境感知
- **漫步**：没事在屏幕底部来回溜达。
- **爬窗**：偶尔跳上当前活动窗口顶部坐着晃腿，或趴着打盹（冒 Zzz）。
- **时段问候**：早起问好、深夜提醒早睡（23 点后会自动进入"打盹模式"）。
- **状态联动**：电量低于 20% 时犯困；前台是音乐播放器时会跟着节拍点头。

### 3. 实用轻功能（陪伴不鸡肋）
- **久坐 / 喝水提醒**：到点冒气泡喊你起来活动、喝水（还会举水杯）。
- **番茄钟**：25 分钟专注倒计时，气泡+托盘双显示。
- **便签**：在托盘里设置便签内容，会定时举着气泡展示。
- **系统监控彩蛋**：CPU 占用过高时擦汗、冒汗珠，吐槽你"电脑要冒烟了"。

### 4. 人设台词与彩蛋
- 全中文傲娇/俏皮/冷幽默台词池，事件触发随机不重复。
- 低概率稀有动作：戴墨镜摆酷、戴皇冠放大招、即兴跳舞。

### 5. 舒适使用体验
- **点击穿透**：开启后完全不挡鼠标（视线跟随/悬停反应仍会触发），适合工作/打游戏。
- **一键隐藏**：收缩到系统托盘，随时双击托盘图标找回。

## 四、打包成 .exe（Windows）
> 本仓库提供两种方式，任选其一：

### 方式 A：本地一键（推荐）
1. 在 **Windows** 上双击 **`build.bat`**（纯 ASCII 通用脚本，任何系统语言都能跑，窗口执行完不会自动关闭）。
2. 首次会自动装依赖（用清华镜像，约 2-5 分钟），产物在 **`dist\Aku.exe`**（绿色单文件，可自行改名，比如改成 `阿酷.exe`）。
3. 若因代理/网络装不上依赖，脚本已自动清除失效代理；仍失败请看常见问题第 2 条。

> 说明：`build.bat` 只是外层，真正的逻辑在 `build_core.bat`；两者都是纯 ASCII，彻底避免中文乱码问题。

### 方式 B：GitHub Actions 自动构建（没有 Python 环境也能出 exe）
1. 把本仓库推到 GitHub（网页上新建仓库 → 上传文件即可）。
2. 在仓库页点 **Actions** → 左侧 **Build Windows EXE** → 右侧 **Run workflow** → 绿色按钮。
3. 等约 3 分钟构建完成，展开 **Aku-Desktop-Pet** 工件 → 下载 `Aku.exe`（可自行改名为 `阿酷.exe`）。
> 云端是干净环境，无杀软干扰，一次成功。

## 五、配置（config.json，首次启动自动生成）
| 字段 | 说明 |
|---|---|
| `pet_name` | 宠物名 |
| `scale` | 显示倍率（默认 1.0） |
| `hotkeys` | 三个全局快捷键 |
| `note_text` | 便签内容 |
| `reminders.sedentary_min` | 久坐提醒间隔（分钟，0=关） |
| `reminders.water_min` | 喝水提醒间隔（分钟，0=关） |
| `reminders.pomodoro_focus/break` | 番茄钟专注/休息分钟 |
| `rare_enabled` | 稀有动作彩蛋开关 |

## 七、常见问题
- **双击 build.bat 报"不是内部或外部命令"乱码 / 窗口一闪而过**：老版本的 `build.bat` 用过中文编码，不同电脑代码页不同会导致乱码甚至闪退。**新版本 `build.bat` + `build_core.bat` 已全部改为纯 ASCII**（彻底无乱码），并用 `call` + 外层 `pause` 保证窗口执行完也不会自动关闭。
- **`[2.5/4]` 报 `qwindows.dll MISSING` / 打包报 `Qt plugin directory ... does not exist`**：这是**杀毒软件在实时删除 Qt 插件 DLL**（360/火绒/Defender 常把 Qt 误判）。解决：①把**项目文件夹**和 **`C:\Users\<你>\AppData\Local\Programs\Python`** 加入杀软白名单后重跑；②或直接走 **GitHub Actions 云端打包**（README 4-B），干净环境一次成功。
- **pip 报 `ProxyError` / 下载失败**：你电脑上存在失效的代理设置（代理软件未运行或环境变量残留）。打包脚本已**自动清除代理环境变量**并改用**清华镜像**安装依赖；若你确实有可用代理，删掉 `build_core.bat` 里的 `set HTTP_PROXY=` 等 4 行即可。
- **本地实在装不上依赖/没有网络**：改用 **GitHub Actions 云端打包**（见第 4 节方式 B），云端自动构建，直接下载 `阿酷.exe`，本地无需 Python。
- **托盘图标不显示**：Win10+ 通常正常；若异常请重启资源管理器或检查是否被杀软拦截。
- **全局热键失效**：`keyboard` 模块未装或被杀软拦，可在托盘菜单操作替代。
- **宠物被全屏游戏遮挡**：置顶层级受系统限制，可先切窗口再召唤。
- **想要更大/更小**：改 `config.json` 的 `scale`（如 1.2 / 0.8）后重启。
